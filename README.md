# Trading Bot — Pionex + Claude

Krypto-Trading-Bot mit Claude als Entscheidungs-"Gehirn", einem selbstgebauten Pionex-MCP-Server als
"Hände", Risk-Gate, Trade-Memory (Learning-File) und einem hellen React-Dashboard.

Siehe [`docs/SETUP.md`](docs/SETUP.md) für die Einrichtung (API-Keys etc.) und
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) für die Architektur.

## Schnellstart

```powershell
.\scripts\start_dev.ps1
```

Backend: http://localhost:8000 · Dashboard: http://localhost:5173
